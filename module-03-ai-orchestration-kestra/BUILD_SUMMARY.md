## 🚀 Quick Start

### 1. Review Documentation
```bash
# Start with quick reference
cat QUICKSTART.md

# Then read overview
cat docs/module-notes.md
```

### 2. Start Kestra
```bash
docker-compose up
# Visit: http://localhost:8080
```

### 3. Configure API Key
- In Kestra UI: Settings → Secrets
- Add: `GEMINI_API_KEY` = your key
- Save

### 4. Run First Flow
- Import `flows/1_chat_without_rag.yaml`
- Execute and observe results
- Record observations
